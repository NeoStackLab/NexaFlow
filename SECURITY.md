# Security policy

Please do not report vulnerabilities in public issues. Send a private security
advisory through GitHub for `NeoStackLab/NexaFlow` with reproduction steps,
affected versions, impact, and any known mitigation.

The project will acknowledge a report as soon as maintainers are available and
coordinate disclosure after a fix is ready. No version is currently declared a
long-term supported release while NexaFlow remains pre-1.0.
